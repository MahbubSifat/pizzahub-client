# PizzaHub

PizzaHub is a pizza ordering and delivery platform. Customers discover local
pizza shops, browse menus and place orders. Vendors manage their menu and
orders. Admins manage users, review menu items and monitor transactions.

## Installation
```bash
git clone https://github.com/MahbubSifat/pizzahub-client
cd pizzahub-client
npm install
```

## Run Locally
1. Copy `.env.example` to `.env.local` and fill in the values.
2. Start the server repository first (see its README).
3. Run `npm run dev` and open `http://localhost:3000`.
